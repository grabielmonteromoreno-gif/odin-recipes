# Odin Recipes
This is the first project of the corse Foundations de [The Odin Project](https://www.theodinproject.com/).

## Descripción
Is a basic web site created using only HTML.
The site features a main page that links to several individual recipes. Each recipe includes an image, a description, a list of ingredients, and preparation steps.

The goal of this project **is not visual design**, but rather to practice and reinforce the fundamentals of HTML and the workflow using Git and GitHub.

## Features

- Main page (`index.html`) with links to the recipes
- Multiple individual recipe pages
- Images for each dish
- Recipe description
- List of ingredients (unordered list)
- Preparation steps (ordered list)
- Navigation between pages

## Skills demonstrated

By completing this project, the following skills are practiced and demonstrated:

- Basic structure of an HTML document
- Correct use of headings (`h1`, `h2`, etc.)
- Creation of internal links between pages
- Ordered (`<ol>`) and unordered (`<ul>`) lists
- Insertion of images using the `alt` attribute
- Organization of project files and folders
- Basic use of Git and GitHub (creating a repository, commits, pushing)
- Writing a clear README
